## Run Locally

Clone the project

```bash
  git clone https://github.com/syhrndraa/CapstoneProject-Dicoding-CPSG47
```

Go to the project directory

```bash
  cd CapstoneProject-Dicoding-CPSG47
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run start-dev
```
